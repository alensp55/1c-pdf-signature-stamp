# Визуальный штамп электронной подписи в PDF из 1С

Добавляет в готовый PDF информационный векторный штамп с переданными реквизитами. Текстовый слой PDF сохраняется.

> Штамп не создаёт, не проверяет и не подтверждает электронную подпись. В самом штампе это указано явно.

## Состав

- `src/pdf_signature_stamp.py` — обработка PDF;
- `src_1c/.../Module.bsl` — серверный модуль 1С;
- `examples/integration_1c.bsl` — пример вызова;
- `examples/job.example.json` — формат задания;
- `tests/` — автоматическая проверка.

## Требования

- Python 3.10+;
- PyMuPDF из `requirements.txt`;
- шрифт с кириллицей;
- серверный контекст 1С с доступом к Python и временным файлам.

## Установка и проверка

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Локальный пример:

```powershell
.\.venv\Scripts\python.exe .\examples\create_demo_pdf.py
cd examples
..\.venv\Scripts\python.exe ..\src\pdf_signature_stamp.py --config .\job.example.json
```

## Задание

```json
{
  "input_pdf": "input.pdf",
  "output_pdf": "output.pdf",
  "certificate": "DEMO-CERTIFICATE",
  "owner": "ПОЛЬЗОВАТЕЛЬ",
  "valid_until": "31.12.2099",
  "power_of_attorney": "DEMO-AUTHORITY",
  "pages": [1, 3],
  "position": "top_right"
}
```

`pages` принимает `all`, `first`, `last` или непустой массив номеров страниц, начиная с 1. `position` принимает
`bottom_left`, `bottom_right`, `top_left` или `top_right`. Для точного размещения вместо позиции можно совместно задать
`stamp_x` и `stamp_y` — координаты левого верхнего угла штампа в пунктах PDF.

Пакет задаётся объектом `{"jobs": [...]}`. По умолчанию обработка останавливается после первой ошибки; ключ
`--continue-on-error` продолжает остальные задания и сохраняет ненулевой код возврата. Каждый результат сначала
создаётся во временном файле рядом с выходным PDF, затем атомарно заменяет целевой файл. При ошибке временный файл
удаляется.

## Подключение к 1С

1. Перенесите `Module.bsl` в серверный общий модуль.
2. Создайте `ДанныеШтампа` и `Настройки`.
3. Вызовите `ДобавитьШтампВоВременноеХранилище()`.
4. Передайте результат штатному механизму подписания.

Для пакета используйте `ДобавитьШтампыПакетом()`. Последний параметр методов обработки принимает адаптер-исполнитель
с методом `Выполнить(Настройки, Аргументы)`, что позволяет заменить запуск процесса в автоматических тестах.

Пути к Python и скрипту храните в настройках системы. Реальные реквизиты в исходники не добавляйте.
