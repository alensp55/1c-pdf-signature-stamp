# Архитектура интеграции

## Граница ответственности

Решение разделено на две части:

- 1С управляет бизнес-сценарием, временным хранилищем, данными сертификата и МЧД;
- Python изменяет только переданный PDF и ничего не знает о метаданных конфигурации 1С.

Получение сертификата и доверенности намеренно не включено в общий модуль. Имена объектов и методы подсистем
электронной подписи зависят от версии конфигурации и БСП. Вызывающий код должен передать только четыре значения:

- отпечаток сертификата;
- представление владельца;
- дату окончания действия;
- номер МЧД.

## Порядок выполнения

1. Прикладной код получает готовый PDF во временном хранилище.
2. Прикладной код формирует `ДанныеШтампа` и `Настройки`.
3. Общий модуль извлекает двоичные данные PDF.
4. Общий модуль записывает входной PDF и JSON-задание во временные файлы.
5. Python добавляет векторный штамп и создает новый PDF.
6. Общий модуль читает результат и переиспользует исходный адрес временного хранилища.
7. Временные PDF, JSON и журналы удаляются.
8. Полученный PDF передается в штатный механизм криптографического подписания.

Штамп нельзя добавлять после создания криптографической подписи: изменение байтов PDF нарушит ее проверку.

## Публичный интерфейс модуля 1С

| Метод | Назначение |
|---|---|
| `НовыеНастройки` | Создает настройки запуска и геометрии штампа |
| `НовыеДанныеШтампа` | Создает контракт данных без зависимости от метаданных |
| `ДобавитьШтампВоВременноеХранилище` | Обрабатывает PDF по адресу временного хранилища |
| `ДобавитьШтампВДвоичныеДанные` | Обрабатывает готовые `ДвоичныеДанные` |
| `ПроверитьОкружение` | Проверяет Python, скрипт и импорт PyMuPDF |
| `ЭтоPDF` | Отфильтровывает файлы по расширению |

## Ошибки и очистка

Стандартный вывод и ошибки Python перенаправляются во временные файлы. При ненулевом коде возврата текст ошибки
включается в исключение 1С. Ошибки удаления временных файлов не заменяют первоначальную ошибку обработки, а
добавляются к ней отдельной строкой.

## Размещение в расширении

Файл `src_1c/CommonModules/ВизуализацияПодписиPDFСервер/Ext/Module.bsl` предназначен для общего серверного модуля:

- серверный;
- вызов сервера разрешен;
- глобальный не требуется;
- безопасный режим должен разрешать COM и запуск внешнего процесса.

Конкретные свойства модуля и разрешения нужно согласовать с политиками вашей информационной базы. Репозиторий
не содержит готовое расширение, потому что версии платформы, конфигурации и БСП у пользователей различаются.
