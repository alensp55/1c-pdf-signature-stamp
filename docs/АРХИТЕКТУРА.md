# Архитектура

1С управляет данными и временным хранилищем. Python только добавляет информационный штамп в PDF и не выполняет
криптографические операции.

## Поток

1. 1С получает PDF и формирует данные штампа.
2. PDF и JSON записываются во временные файлы.
3. Python создаёт новый PDF со штампом.
4. 1С читает результат и удаляет временные файлы.
5. PDF передаётся на криптографическое подписание.

## Интерфейс 1С

| Метод | Назначение |
|---|---|
| `НовыеНастройки` | Параметры запуска и геометрии |
| `НовыеДанныеШтампа` | Данные сертификата и доверенности |
| `ДобавитьШтампВоВременноеХранилище` | Обработка PDF из временного хранилища |
| `ДобавитьШтампВДвоичныеДанные` | Обработка двоичных данных |
| `ДобавитьШтампыПакетом` | Независимая обработка набора PDF с результатом по каждому элементу |
| `ПроверитьОкружение` | Проверка Python и PyMuPDF |

Модуль выполняется на сервере. Вызов внешнего процесса и COM должны быть разрешены политиками системы. Для тестов и
альтернативного запуска можно передать исполнитель с методом `Выполнить(Настройки, Аргументы)`.

Python нормализует задание до неизменяемого DTO, валидирует страницы, геометрию и координаты до изменения документа.
Выходной PDF создаётся во временном файле в целевом каталоге и заменяет целевой путь только после успешного сохранения.
