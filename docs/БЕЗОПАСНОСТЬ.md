# Безопасность

Не храните в репозитории:

- реальные PDF;
- ФИО, адреса и учётные записи;
- названия организаций и баз;
- сертификаты, доверенности и закрытые ключи;
- пароли, токены и журналы;
- адреса серверов и абсолютные пути.

Данные штампа передаются через временный JSON, а не через командную строку. В интеграции 1С после обработки удаляются
входной PDF, результат, JSON и журналы. Python пишет результат во временный файл и удаляет его при любой ошибке.

Службе 1С достаточно прав на запуск Python, чтение скрипта и шрифта, работу с отдельным временным каталогом.
Локальный администратор не требуется.

Перед публикацией проверьте текущие файлы и историю Git на секреты, реальные реквизиты и приватные вложения.
