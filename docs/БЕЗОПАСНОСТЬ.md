# Безопасность и обезличивание

Штамп содержит персональные данные и технические идентификаторы. В продуктивной системе к ним нужно относиться
так же, как к данным исходного подписанного документа.

## Что нельзя хранить в репозитории

- реальные PDF и их фрагменты;
- ФИО сотрудников, имена учетных записей и адреса электронной почты;
- названия организаций, подразделений и информационных баз;
- отпечатки, серийные номера и файлы сертификатов;
- номера МЧД и другие идентификаторы доверенностей;
- пароли, токены, закрытые ключи и контейнеры ключей;
- реальные пути серверов, сетевые адреса и имена компьютеров;
- журналы запуска, дампы, временные JSON-файлы и файлы ошибок;
- файлы внешних обработок и расширений, если право на их публикацию не подтверждено.

## Безопасная передача параметров

Реквизиты штампа передаются через временный JSON-файл. Это предпочтительнее аргументов командной строки:
аргументы могут быть видны в списке процессов и средствах мониторинга.

После завершения обработки 1С должна удалить:

- входную временную копию PDF;
- выходную временную копию PDF после чтения результата;
- JSON-задание;
- файлы стандартного вывода и ошибок.

Учетной записи службы сервера 1С нужны только следующие права:

- чтение и выполнение для Python и скрипта;
- изменение для отдельного рабочего каталога;
- чтение системного шрифта, выбранного для кириллицы.

Не выдавайте службе права локального администратора только ради запуска Python.

## Проверка перед публикацией

Перед каждым публичным выпуском:

1. Просмотрите полный список файлов командой `git status --short`.
2. Просмотрите подготовленные изменения командой `git diff --cached`.
3. Найдите абсолютные пути Windows: `git grep -nE '[A-Za-z]:\\\\'`.
4. Найдите адреса электронной почты: `git grep -nE '[[:alnum:]._%+-]+@[[:alnum:].-]+'`.
5. Найдите возможные токены и секреты: `git grep -niE 'password|пароль|token|secret|BEGIN.*PRIVATE KEY'`.
6. Отдельно проверьте известные названия организаций, ФИО, учетные записи и номера сертификатов.
7. Убедитесь, что в истории Git нет ранее добавленных конфиденциальных файлов.

Автоматический поиск не заменяет ручной просмотр. Идентификатор или название может не совпасть с шаблоном.
